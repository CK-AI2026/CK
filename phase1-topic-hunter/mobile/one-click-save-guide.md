# 手机端一键存入指南 · One-Click Save

## 核心场景
刷到好内容 → 点分享 → 选Coze Bot → 发送 → AI自动分析 → 推送结果 → 打开Notion查看

## 操作步骤
1. 下载Coze App，登录账号
2. 创建选题猎手Bot，绑定工作流
3. 把Bot添加到分享列表（iPhone: 分享→更多→编辑→添加扣子）
4. 日常使用：刷到想存的视频→分享箭头→更多→扣子→选题助手Bot→发送
5. 等10-30秒，Bot回复分析结果

## Bot对话话术
人设：你好，我是你的选题助手，把抖音/小红书的内容链接分享给我，我帮你分析爆款潜力并存入Notion选题库。

分析完成回复模板：
✅ 分析完成！已存入选题库
📌 选题：{title}
🏆 综合评分：{total_score}/100
📊 赞赞比：{ratio}（{grade}级）
💡 核心痛点：{core_pain}
📝 查看Notion详情：{notion_url}
回复"通过"把它移入素材库，回复"淘汰"直接pass～

## 快捷指令增强（iOS）
- 快捷指令1：快速存选题（获取剪贴板→打开Coze→发送到选题助手）
- 快捷指令2：语音录入灵感（听写文本→发送到选题助手）
